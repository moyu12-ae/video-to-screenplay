# 剧本格式标准参考：好莱坞 Spec 与中式场号制

本文件定义正式剧本格式标准与编译规则，用于把逆向还原出的视频时间线转化为专业、可投产的剧本。

---

## 1. 双行业标准总览

| 维度 | 标准 A：好莱坞 Spec Script（行业通用） | 标准 B：中式影视文学剧本（场号制标准） |
| :--- | :--- | :--- |
| **主要适用** | 国际制片、好莱坞制片厂、Fountain/Final Draft 工作流 | 国内电视剧/电影、剧集、广电审查、拍摄团队 |
| **场景头** | `INT./EXT. LOCATION - DAY/NIGHT` | `场号：1-1` / `第1场 【内景/外景】地点——日/夜 [气氛]` |
| **动作段** | 现在时、主动语态，角色首登场名字全大写 `ALICE (28)` | `△` 引导的视听动作段落，客观现在时，人物首登场 `△【张三】（25岁）` |
| **台词块** | 居中角色名 + 缩进台词 + 扩展标注 `(V.O.)`/`(O.S.)` | 顶格或居中人物名，双冒号或换行，标明 `【画外音】` / `【内心独白】` |
| **声画扩展标注** | `(V.O.)`, `(O.S.)`, `(CONT'D)`, `(PRE-LAP)` | `【画外音】`, `【内心独白】`, `【电话音】`, `（续）` |
| **无声动作节拍** | 用动作段明确写出肢体节拍与静默 | `△ [无声镜头/动作节拍]` 标注预计时长与视听信息 |
| **排版** | Courier 12pt，严格英寸页边距（左 1.5"，右/上/下 1"） | 宋体/黑体，1.25~1.5 倍行距，场号与 △ 分明 |

## 2. 标准 A：好莱坞 Spec Script 格式（兼容 Fountain）

### 2.1 场景标题（Sluglines）
每个场景以一行 slugline 开头，包含三个必备要素：
1. **机位内外景**：`INT.`（内景）、`EXT.`（外景）、`INT./EXT.`（车内、门口等）。
2. **场景/地点**：由泛到具体（`INT. POLICE PRECINCT - INTERROGATION ROOM`）。
3. **时间**：`DAY`、`NIGHT`、`DUSK`（黄昏）、`DAWN`（黎明）、`CONTINUOUS`（紧接）、`LATER`（稍后）。

```fountain
INT. DETECTIVE OFFICE - NIGHT

Rain lashes against the grime-streaked window. Neon glare from the street spills across a cluttered mahogany desk.
```

### 2.2 动作块
- 用**现在时**、主动语态书写（`is doing` → `does`）。
- **角色名大写**：会说话的角色首次登场时，名字全大写并附年龄或识别特征：`JOHN DOE (40s), haggard and unshaven...`
- **音效与关键道具大写**：主要剧情内音效要大写：`A gun CLICK sounds. A glass SHATTERS.`
- **视觉地面真实**：只写镜头能拍到、录音能录到的内容。禁止内心心理旁白（"He wonders why he was born" 是违规的；应改写为 "He stares at the tarnished photo, jaw clenched"）。

### 2.3 角色与台词块
- **角色名**：大写，单独成行。
- **扩展标注**：
  - `(V.O.)` — Voice Over 画外音：说话者不在场景物理空间内（旁白、电话声音、内心想法）。
  - `(O.S.)` — Off Screen 画外：说话者在场景空间内但不在画面中。
  - `(CONT'D)` — Continuous 连续：台词被动作段打断后由同一角色继续。
- **括注（Wrylies）**：紧贴角色名下方的括号内简短情绪或念法提示：`(whispering)`（低声）、`(through tears)`（含泪）、`(into radio)`（对着无线电）。除非以专有名词开头，否则不大写。
- **逐字台词**：台词与提取字幕逐字一致。绝不缩写或改写。

```fountain
DETECTIVE VANCE
(lighting a cigarette)
You were there at midnight. Don't lie to me.

SUSPECT (O.S.)
I was three miles away, Vance! Check the cameras!
```

### 2.4 转场
- 置于右边距、全大写：`CUT TO:`、`DISSOLVE TO:`、`SMASH CUT TO:`、`FADE OUT.`

## 3. 标准 B：中式场号制影视文学剧本规范

### 3.1 场号与场景头（Slugline Header）
标准格式：
`场号：[集数]-[场次]` 或 `第[X]场`
`【内景 / 外景】具体地点——时间（日/夜/晨/昏） [天气/环境气氛]`

```text
第1场 【内景】市刑侦支队·审讯室——夜 [暴雨]

人物：沈锐、方哲、警员小汪
```

### 3.2 视听动作段落（△ 视听语言规范）
- 每一个镜头动作、环境变化、人物肢体调度均以 `△` 起行。
- 坚持"目击者叙事原则"：只能写摄影机能拍到、录音机能录下的客观视听内容。
- **人物初次出场**：用中括号突出，标注年龄、体态与标志性特征：
  `△【沈锐】（40岁左右，身穿黑风衣，面色苍白，左颊有一道微小的疤痕）推门走入。`
- **无声镜头/视觉节拍（Silent Action Beats）**：
  若一段镜头无台词（如潜行、搜证、对峙沉思），必须写明动作细节与视听信息：
  `△ 沈锐在审讯椅前停住脚步，从口袋掏出一副白手套缓缓戴上。审讯室内只有白炽灯发出的嗡嗡电流声。（镜头停留约3秒）`

### 3.3 台词与对白排版
- 角色名单独成行或顶格后接冒号。
- **画外音**：明确标注 `【画外音】` 或 `（O.S.）`。
- **内心独白**：明确标注 `【内心独白】` 或 `（心声）`，不可与正常动作混淆。
- **电话/通讯音**：标注 `【电话音】` 或 `【无线电音】`。
- **台词内容**：逐字忠实于提取字音，不得随意润色。

```text
沈锐
（将案卷重重摔在铁桌上）
昨晚十二点，你在哪儿？

方哲【内心独白】
他的眼神在发飘。他在试探我。

方哲
支队档案室。你可以调走廊监控。
```

## 4. 声画关系映射矩阵

把 `aligned_timeline.json` 编译成剧本格式时，按下列矩阵映射时间线事件：

| 时间线 `av_relation` | 好莱坞格式标注 | 中式格式标注 | 编译动作 |
| :--- | :--- | :--- | :--- |
| `ON_SCREEN` | `CHARACTER` | `人物名` | 角色在画面中开口。动作段描写表情与口型同步。 |
| `VOICE_OVER` | `CHARACTER (V.O.)` | `人物名【画外音】` / `【旁白】` | 非剧情内声源。动作段描写同时发生的另一处画面动作。 |
| `OFF_SCREEN` | `CHARACTER (O.S.)` | `人物名（O.S.）` / `【画外】` | 说话者在场景内但不在画面中。动作段描写画面内主体的反应。 |
| `INTERNAL_MONOLOGUE`| `CHARACTER (V.O.)` + `(thought)` | `人物名【内心独白】` | 角色在画面中但闭口。动作段注明表情静止。 |
| `REACTION_SHOT` | `CHARACTER (O.S.)` | `人物名（O.S.）` | 说话者 A 的声音叠在说话者 B 的画面关键帧上。动作段必须描写 B 的反应！ |
| `SILENT_ACTION` | Action Block | `△ [动作节拍]` | 专设动作段，描写关键帧画面、情绪与道具。 |

## 5. 剧本编译质量规则

1. **逐字保真**：台词绝不现代化、概述或修改。若 OCR 抓到俚语或残句，原样保留。
2. **零臆测心理**：绝不写"她感到悲伤"。要写"泪水在她眼里打转；她垂下眼，把袖口拉过来裹住手指"。（细则见 §6.5 视听绝对性）
3. **时间码可追溯**：剧本中每个场头都应保留可选的制作时间码备注：`[TC: 00:01:23.450 - 00:01:45.200]`，用于制作对齐。
4. **节拍完整性**：超过 1.5 秒的无声动作段绝不跳过——它们代表关键的镜头调度。

## 6. 成品 Markdown 版式（v2 拼装标准）

Markdown 交付物的版式以本节为准；基准样张为第 1、2 集成品剧本。核心分工：**创意层（场标题、△ 动作、表演提示、台词合并分组）由写作阶段自由撰写；确定性层（时间码、台词原文）由拼装脚本注入——脚本不改写任何创作内容。**

### 6.1 场头（H2 二级标题，供检索与目录）

```markdown
## 场 7【海面·燃烧的帆船】（00:06:15 - 00:07:42）
```

- 标题 = 地点+事件，6~14 字（如【王座之侧】【驿站·误会与和解】），由写手起名；
- 时间码括注 `（HH:MM:SS - HH:MM:SS）` 由拼装器按 scene_manifest 确定性注入，写手不手写。

### 6.2 时空行（场头下一行）

```markdown
**内景·日**｜紫晶珊瑚背景
**外景·夜**｜字幕卡：`（公元1792年）`
```

全角竖线「｜」后接气氛、字幕卡、道具等注记。

### 6.3 台词行（同一说话人连续台词合并）

```markdown
**乳母**（躬身）：世子恕罪／小姐她 似乎非比寻常／与已故的老王爷如出一辙的气息
**云铮**（暴起，戟指）：根据家规／私运禁物 即是死罪／拿下她！
```

- 同一角色连续说话**合并为一行**，句间用全角斜杠「／」分隔；说话人切换才另起一行；
- 表演提示写在名字后的括号里；画外/独白同样入括号：`**云铮**（画外，遗言）：…`、`**小满**（内心独白）：…`；
- 台词原文逐字保真（由 `[[SUB:n]]` 占位符回填），「／」只是排版分隔符，不属于台词。

### 6.4 △ 动作段（导演笔记）

△ 不是场景说明书，是导演笔记，三类用途：**演出指示**（一句话该怎么说）、**表演指导**（表情与小动作）、**镜头强调**（特写/缓推/骤白/声画对位）。写光、写物、写身体、写声音。样张水准示例：

```markdown
△ 铜镜只剩一点将熄的微光。云铮的音容浮现在光晕里。
△ 小满双手按上镜面——镜的另一侧，一只涂着黑甲的手（影卫）与她隔镜相抵。青金的光纹在镜面炸开。
```

密度基准：场首必有一段定场 △；台词的情绪转折处必须插一拍 △；超过 1.5 秒的无声节拍单独立 △ 并标时长。禁止"两人交谈""气氛尴尬"式空泛句。

### 6.5 视听绝对性："目击者原则"（只写拍得到的东西）

编剧不是小说家。小说写内心，戏剧写言语，而电影写外部处境与物理现实。

**删掉一切摄影机拍不到的心态与回忆：**

```markdown
❌ △ 听到这句话，李雷想起了五年前母亲在病床前握着他的手，心中涌起一股无法遏制的悔恨。
   （摄影机拍不到五年前，也拍不到"悔恨"）

✔️ △ 李雷动作僵住。他死死攥住拳头，指甲几乎陷进肉里，下颌肌肉紧绷。
   （演员能演，摄影机能拍）
```

**拒绝否定式句式（Notnot 原则）：** 银幕上呈现的是"有什么"，而不是"没什么"。

```markdown
❌ △ 他没有回答，什么也没做，房间里一个人也没有。

✔️ △ 他面无表情地看着对方，保持沉默。空荡荡的房间唯有座钟摆动。
```

### 6.6 版式禁止项

- 禁止 `> 概要：` 引用行进入正文——概要只出现在场次总表；
- 禁止为逐句台词逐行重复人名（应按 6.3 合并）；
- 禁止正文出现 `SPEAKER_*` 暂定标签（一律掩蔽为「人物」）；
- 禁止手写时间码进 H2（由拼装器统一注入，保证与清单一致）。
